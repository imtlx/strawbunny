# strawbunny

A tiny strawberry distribution game featuring a silly bnuuy, written in x86-64 assembly using FASM.

## Build

```bash
make
```

## Usage

```bash
out/strawbunny
```

Distribute strawberries, check your stock, and patpat cute bnuy!

## Requirements

- Linux x86-64
- FASM
- Make
